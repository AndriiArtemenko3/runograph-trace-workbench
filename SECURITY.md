# Security policy

## Supported version

RunoGraph Trace Workbench is pre-alpha software. Only the current default
branch is maintained, and no production deployment or response-time guarantee
is offered.

## Reporting a vulnerability

If you identify a suspected vulnerability while viewing the repository or
during evaluation permitted by a separate written agreement with the copyright
holder, do not open a public GitHub issue. Email
`andrii.art.design@gmail.com` with:

- the affected commit or version;
- a concise description of the impact;
- evidence obtained within that agreement; and
- any suggested mitigation.

Do not send credentials, customer data, production traces, database files, or
unredacted confidential paths. Use a minimal synthetic reproduction and agree
on a secure transfer method before sharing any additional material.

This policy does not grant permission to download, execute, scan, exploit, or
modify the software. Contact the copyright holder before performing any further
testing not already covered by that separate written agreement.

Reports are reviewed on a best-effort basis. This policy does not turn the
local development API into a supported public service; its documented
loopback-only boundary still applies.
